# Vision Automation Design System

A dark, glass-styled design system and interactive showcase. It was built from eight Figma screens of the Unilever Vision Automation product (file `F3mlhgMw589Hs49rxXSFXR`) and keeps the structure, scales, behaviour and accessibility contracts of the previous DEOC design system.

The project is independent: it shares no code, dependencies or build output with the previous showcase, which was only read.

## Quick start

```bash
npm install
npm run dev        # http://localhost:5181
npm run build      # spec → typecheck → production build in dist/
npm run preview    # serve dist/ on http://localhost:4174
```

Requires Node 20+. The browser checks use an installed Chrome or Edge through `playwright-core`; no browser is downloaded. Set `CHROME_PATH` if neither is found.

## How it is built

```
spec/DESIGN_SYSTEM.md ──► scripts/extract-spec.mjs ──► src/generated/ds.css          (every ```css block, + .is-hover/.is-focus/.is-active mirrors)
   (single source of truth)                         ├─► src/generated/text-styles.css (.ds-ts-<name> from the named text-styles table)
                                                    └─► src/generated/spec.json       (sections, tokens, primitives, registry, crops, decisions)
```

- **`spec/DESIGN_SYSTEM.md` is the only place a value is defined.** Edit the spec, then run `npm run spec` (the dev and build scripts run it for you). Never edit `src/generated/`.
- Components (`src/components/ds/`) and charts (`src/charts/`) use only `var(--ds-*)` tokens and spec classes. `npm run check:tokens` fails on any undeclared token, or on any colour literal outside the few files that mirror spec values.
- Figma functional icons are generated by `node scripts/build-figma-icons.mjs` from `public/figma/icons/` into `src/components/ds/figmaIcons.ts`.

## Quality checks

```bash
npm run typecheck            # tsc --noEmit
npm run check:tokens         # static token / colour-literal scan
npm run check:browser        # axe (WCAG 2.2 A/AA), overflow at 390/768/1024/1440/1680, console errors, screenshots
npm run check:interactions   # scripted keyboard, focus, overlay, validation and timing checks
npm run qa                   # all of the above after a build
node scripts/shoot-apps.mjs  # 1920 × 1021 captures of the eight screens for comparison with Figma
```

Results are written to `public/qa-report.json`, which the Quality page shows, and to `qa-output/`. See `QA_REPORT.md` for the latest run.

## Constraints followed

- Dark theme only; there is no light theme.
- No colour literals in components. Every value comes from a spec token.
- Nothing has been published, committed, pushed or deployed. The Figma file and the previous showcase were only read.
