# Design system diff — previous DEOC system → Vision Automation

> **Superseded in part by D-10 (2026-10-24).** The DEOC app's Design System 02 is now the reference: structure, type and composition were aligned to it (spec §14, Revision 4; R-29 – R-31), and `npm run check:deoc` proves the match. Rows below about type sizes (`display` 28 px, 14 px KPI labels / table headers), spacing (24 px gutter, card padding) and sizes (72 px rows, 102 px KPI cards) describe the earlier hybrid version; the current values are in `spec/DESIGN_SYSTEM.md` §3.

How the new system relates to the previous one (`C:\Users\riyag\Documents\design-system-showcase`, read only). Token tables are generated by comparing both projects' `src/generated/spec.json`; reasons come from `spec/DESIGN_SYSTEM.md`.

## Rule applied (decision D-0, "hybrid")

1. Every **scale** and every **token name** of the previous system is kept.
2. A Figma value that **sits on an existing scale** is adopted → *Adopted (on scale)*.
3. Off-scale Figma values are normalised to the nearest step and logged (R-01, R-02).
4. One new type size, **28 px `display`**, enters as a named exception (D-1).
5. Colours, effects, gradients, shadows, status treatments and charts are **rebuilt** from the frames, as the brief requires → *Rebuilt*. Surface tokens with no Figma counterpart are **removed** and replaced as listed below.
6. Where a Figma colour fails WCAG AA it is changed to the nearest passing value → *AA adjustment* (R-03 … R-08).

## What stayed the same

- **Type scale** 10 / 11 / 12 / 14 / 16 / 18 / 20 / 24 px, the font (Inter), weights and every named text style; tracking rules for headings and uppercase labels.
- **Spacing scale** (4 px grid with 2 px half-steps), radius steps, control heights (40 / 32 / 48), icon sizes.
- **Motion** durations and easing, reduced-motion handling; **z-index** layers.
- **Component anatomy, behaviour and accessibility contracts** (§5.1 – §5.55 keep the previous numbering): overlay focus and Escape rules, discard confirmation, validation on submit, keyboard models for select, tabs, radio cards, pagination, tooltips, chart tooltips.
- **Chart structure**: axes, number formatting, rich tooltip, legend styles, heat-scale contrast snapping.
